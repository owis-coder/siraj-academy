# تحليل الموقع المرجعي: منصة قمة التعليمية

> التحليل أُجري على الصفحات المتاحة علنيًا (الرئيسية، الدورات، المدرسون، الطلبات، نموذج طلب شرح جديد).
> لا يوجد أي نسخ للشعار أو النصوص أو الصور — الاعتماد على البنية وتجربة الاستخدام فقط.

## 1. البنية العامة والتنقل
- شريط علوي: شعار يمين + قائمة (الرئيسية، الدورات، المدرسون، طلبات الشرح، اطلب شرح خصوصي) + زر تسجيل دخول بارز.
- ظاهرتان بارزتان تُبنى عليهما الخدمة: (الطلبات الجارية) و(المدرسون) مضافتان في مستوى واحد من التنقل = قلب المنصة.
- زر CTA مكرر: "اطلب شرح خصوصي" يظهر في الشريط ومرة في نهاية القائمة (تعزيز قوي).
- تذييل: وصف المنصة + معلومات مهمة (خصوصية/شروط/استرداد) + استكشف (مزايا، أطباء/مدرسون، أسئلة شائعة) + تواصل.
- نافذة دخول منبثقة من الهيدر، مع صفحات مخصصة للتسجيل.

## 2. الصفحة الرئيسية — ترتيب الأقسام
1. Hero: "تعلّم موادك الجامعية بطريقة أبسط" + وصف + زرّان (ابدأ الآن / استكشف الدورات) + Hero visual.
2. شريط أرقام: دورة تعليمية 216+ / 36+ جامعة / 155+ معلم / 24/7 — (سنعرض أرقامًا حقيقية من قاعدة البيانات فقط).
3. "اختر جامعتك وابدأ": بطاقات جامعية صغيرة (اسم + عدد المقررات) + رابط عرض جميع الجامعات.
4. "الطلبات الجارية": بطاقات طلبات برقم تسلسلي (#727) + حالة (متاح / تم اختيار مدرس) + المادة + الوصف + الجامعة + التاريخ + عدد العروض.
5. "أحدث الدورات": تبويبات تصفية حسب الجامعة + بطاقات دورات (عنوان | المدرس | السعر/مجاني | زر عرض الدورة).
6. "آراء طلابنا": تقييمات 5/5 مع اقتباس واسم الطالب ورابط الدورة.
7. قسم "كل ما تحتاجه لتتقدم بثقة": 4 مزايا (تواصل مباشر، اختبارات، تعلّم حسب الحاجة، من أي مكان).
8. CTA ختامي "جاهز تبدأ رحلة تعلّم أبسط؟" + تذييل.

## 3. صفحة الدورات
- تسلسل تصنيفي هرمي كامل: الجامعات السعودية ← الكلية ← القسم (التخصص)، وفيه فروع فعلية من جامعات سعودية حقيقية (KSU, PNU, KFU.. إلخ) مع عمادات السنة الأولى المشتركة/التحضيرية.
- نفس نمط التسلسل: الجامعة ← الكلية ← القسم ← المقرر. (لا يوجد "المستوى" صراحة في القوائم — سنضيفه اختياريًا مشروعنا).
- بحث داخل المقررات + فلاتر + ترقيم صفحات + بطاقة مقرر: صورة، عنوان برمز المقرر (ACCT 121)، المدرس، عدد الطلاب، السعر نقطة، "عرض الدورة".
- تصنيفات مستقلة أيضًا: "دورات عامة" (اختبارات مهنية، تطوير مهني، برامج المنصة).

## 4. صفحة المدرسين
- فلترة: بحث بالاسم/المادة + الجامعة + الترتيب (الأحدث/الأقدم). عرض عدد النتائج.
- بطاقة مدرس: صورة، الاسم، نبذة مقطوعة، التخصصات، الجامعة/جهة التدريس، "عرض الملف المهني".
- صفحة الملف المهني: تفاصيل المؤهل والخبرات والمواد.

## 5. صفحة الطلبات الجارية
- بحث (مادة/جامعة) + فلتر حالة (متاح للتقديم / تم اختيار مدرس / مغلق) + ترتيب.
- بطاقة: #رقم، حالة، المادة، "طلب شرح"، الوصف، الجامعة، التاريخ، عدد الطلاب المرفقيين، عدد العروض، زر تفاصيل وتقديم (للمدرسين).
- ترقيم صفحات.

## 6. نموذج "طلب شرح جديد" (صفحة التحويل الرئيسية للإيراد)
- ترويسة إقناعية: "ابدأ من المادة، واترك التنظيم علينا" + 3 ضمانات (مراجعة قبل النشر، حساب متابعة تلقائي، تواصل واتساب).
- 3 خطوات: (1) بيانات الطالب: الاسم + واتساب (تحقق صيغة 9665...) + الجامعة ← الكلية (يظهر مشروطًا) ← القسم.
  (2) تفاصيل الشرح: عنوان المادة، ماذا تريد أن تفهم، عدد الطلاب، طريقة الشرح (عن بُعد/حضوري/كلاهما)، المدة (فوري/يوم/أسبوع/فصل)، الموقع، الميزانية بالريال (اختياري).
  (3) المرفق أو الرابط: رفع ملف (حتى 25MB) أو رابط Drive/OneDrive.
- بعد الإرسال: الطلب يذهب للإدارة للمراجعة قبل النشر — ثم عروض المدرسين — ثم اختيار.
- "رحلتك بعد الإرسال" بـ 4 خطوات تعليمية.
- لو ليس لديك حساب: يُنشأ حساب تلقائيًا.

## 7. ملاحظات UX استفدنا منها لمشروعنا (بدون تقليد بصري)
- رقم الطلب العلني (#) يعطي إحساس التتبع والاحتراف.
- الحالة تظهر دائمًا كبطاقة ملونة صغيرة (متاح/تم اختيار مدرس/مغلق).
- العروض مرئية للطالب صاحب الطلب مع اختيار الأنسب، الميزانية اختيارية.
- الطلبات تمر بإدارة بشرية قبل النشر (مراجعة قبل النشر).
- كل شيء JSON منقول إلى مشروعنا老乡: نفس نمط التسلسل الجامعة←كلية←قسم←مقرر لكن نمضي أبعد: التخصص والمستوى وكلية اختيارية (يمكن تخطيها) + مستوى إشكالة البحث الشامل.
