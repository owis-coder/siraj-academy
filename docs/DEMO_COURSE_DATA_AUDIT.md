| الملف | الوظيفة | هل ينشئ دورات؟ |

## 2) سبب التكرار

**السبب الجذري: `seed-real-data.ts` ينشئ نفس عناوين المقررات لكل جامعة.**

```ts
// COLLEGES_DATA يحتوي عناوين مقررات ثابتة، ثم:
for (const uni of universities) {
  for (const college of COLLEGES_DATA) {
    for (const crs of college.courses) {
      newCoursesData.push({ title: crs.title, code: null, universityId: uni.id, ... });
```

- 32 جامعة × نفس عناوين المقررات = عشرات المقررات بنفس الاسم (مثل «مبادئ البرمجة») في جامعات مختلفة، وبدون `code` يميّزها.
- الواجهة العامة (`/courses`) تعرض العنوان فقط، فتظهر قائمة بأسماء متطابقة يبدو أنها تكرار.
- سبب ثانوي: عند إنشاء المدرس دورة بـ`courseTitle` يدويًا، ينشئ الخادم `Course` جديدًا كلما اختلف النص قليلًا (مسافة/همزة/حالة أحرف) بدل إعادة استخدام مقرر موجود.

**ملاحظة مهمة:** البيانات ليست تكرارًا لنفس الصف في قاعدة البيانات؛ بل صفوف مختلفة (جامعة/معرّف مختلف) تحمل الاسم نفسه. لذلك لا يجوز حذفها عشوائيًا.

## 3) الإجراء الآمن المنفَّذ + المطلوب

### أ) أداة فحص آمنة (جديدة)
`apps/server/prisma/demo-dedupe.ts`:
```bash
# فحص فقط (افتراضي) — لا يغيّر أي سجل
npx tsx prisma/demo-dedupe.ts

# تطبيق: يُخفي (isVisible=false) المقرر المكرر الفارغ فقط
npx tsx prisma/demo-dedupe.ts --apply
```
شروط الأمان:
- لا `DELETE` ولا `TRUNCATE` إطلاقًا.
- يُستثنى أي مقرر لديه دورات أو اشتراكات (يبقى محميًا).
- يُبقي أقدم نسخة ظاهرة.

### ب) بيانات تجريبية متنوعة (جديدة)
`apps/server/prisma/seed-demo-diverse.ts` (سكربت `seed:demo:diverse`) يضيف 15 مقررًا بمجالات متنوعة وأسماء فريدة (بادئة `DEMO-DIV-`):

1. أساسيات البرمجة بلغة Python
2. تطوير تطبيقات الويب الحديثة
3. قواعد البيانات وSQL
4. شبكات الحاسوب وبروتوكولاتها
5. أمن المعلومات والتشفير التطبيقي
6. أساسيات الذكاء الاصطناعي وتعلّم الآلة
7. الرياضيات الهندسية والتحليل العددي
8. الفيزياء العامة للمهندسين
9. أساسيات المحاسبة المالية
10. إدارة المشاريع والجدولة
11. اللغة الإنجليزية الأكاديمية
12. مهارات البحث العلمي
13. تحليل البيانات باستخدام Python
14. تصميم واجهات المستخدم وتجربتها
15. أساسيات أنظمة التشغيل

التنويع يشمل:
- 6 مدرسين تجريبيين بأسماء وتخصصات درجات علمية مختلفة.
- 8 مستويات سعرية مختلفة.
- عدد دروس مختلف (3–6).
- حالات متعددة: `PUBLISHED` (8)، `PENDING_REVIEW` (3)، `DRAFT` (2)، `NEEDS_REVISION` (1)، `REJECTED` (1).
- روابط YouTube متعددة، واعتماد فيديو فقط للدورات المنشورة.

### ج) لماذا لم يُشغَّل السكربت الآن
- `DATABASE_URL` في `apps/server/.env` يشير إلى قاعدة **Neon خارجية** (ليست بيئة اختبار معزولة).
- تعليمات المهمة تمنع تعديل بيانات إنتاجية دون موافقة صريحة.
- لذلك: أُضيف السكربت والأداة، ولم يُنفَّذ أي `DELETE/TRUNCATE`، ولم تُكتب أي بيانات في القاعدة.

## 4) خطة التطبيق على بيئة آمنة (مقترحة)

1. أخذ نسخة احتياطية: `npm --prefix apps/server run backup:db`.
2. إنشاء قاعدة اختبار مستقلة (Docker محلي) وضبط `DATABASE_URL` لها.
3. `npx prisma migrate deploy`.
4. `npm --prefix apps/server run seed:demo` ثم `seed:demo:diverse`.
5. `npx tsx prisma/demo-dedupe.ts` (فحص) ثم `--apply` بعد مراجعة القائمة.
6. التحقق من صفحات `/courses` و`/teachers` بالعربية والإنجليزية.
