# أكاديمية سراج التعليمية — منصة موصولة (المرحلة التأسيسية مكتملة)

منصة أكاديمية سعودية لطلاب الجامعات: تصفّح (جامعة ← كلية ← تخصص ← مستوى ← مقرر)، دورات يديرها مدرسون، طلبات شرح بعروض أسعار، متجر خدمات طلابية، دفع تحويل بنكي يدوي بمراجعة سند، محادثات، إشعارات، ولوحة إدارة كاملة — بهوية سراج الداكنة الذهبية.

## البنية
```
apps/server   Node.js + Express + TypeScript + Prisma (PostgreSQL) + Socket.IO + Zod + JWT
apps/web      React 18 + Vite + TypeScript + Tailwind (RTL، IBM Plex Sans Arabic، ثيم سراج)
assets/brand  أصول الشعار الأصلية (علامة + ترصيف أفقي + بوستر)
docs/         تحليل المرجع + الهوية + عقد API + سكربت اختبار دمج e2e.mjs
docker-compose.yml  PostgreSQL dev (5432 / siraj / siraj_dev_2024)
```

## تشغيل سريع
```powershell
# 1) قاعدة البيانات (إما docker أو أي postgres محلي على 5432)
docker compose up -d
cd apps/server
npm install
npx prisma migrate dev --name init   # ينشئ المخطط تلقائياً
npx prisma generate
npm run seed                          # إعدادات + حساب إداري + 32 جامعة سعودية + صفر بيانات وهمية
npm run dev                           # API على 4000

cd ../web
npm install
npm run dev                           # الواجهة على 5173 (پروكسي /api → 4000)
```

حساب الإدارة بعد seed: `admin@siraj.sa` / `Siraj@2026Admin` (**غيّره فورًا من الإعدادات**).

## حساب اختبار الدمج الشامل (E2E)
```powershell
node docs/e2e.mjs      # 34 فحصًا: صلاحيات، اعتماد مدرس، نشر دورة، دفع بسند ومراجعة، عروض، إعلانات، إحصائيات
```
> يتطلب قاعدة بيانات تعمل. للمسح بعد الاختبار: `npx prisma migrate reset --force` ثم `npm run seed`.

## الضمانات المفروضة على الخادم
- مدرس PENDING لا ينشر شيئًا حتى اعتماد الإدارة.
- الدفع لا ينجح تلقائيًا: سند → مراجعة إدارة → منح وصول + إشعارات (أو رفض + إشعار).
- طلبات الشرح تنشرها الإدارة؛ العروض على المفتوح فقط؛ القبول يُنشئ طلبًا رسميًا وغرفة محادثة.
- تعديل إعلان معتمد يعيده تلقائيًا للمراجعة.
- كل الإحصائيات aggregate حقيقي — لا أرقام وهمية في أي مكان.
